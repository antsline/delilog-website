## 1. 点呼記録簿は自由様式｜このテンプレートの中身

結論: 法令が決めているのは「何を記録するか」で、用紙の形は決まっていません。

貨物自動車運送事業輸送安全規則の第7条は、点呼の内容と、次の事項の記録を求めています。点呼を行った人と受けた人の氏名、車両番号、点呼の日時、点呼の方法などです。そして、その記録を1年間保存します。

国土交通省は、貨物軽自動車運送事業者向けに「点呼記録簿の例」を配っています。ファイルは Word 形式です。配布ページには、点呼の内容は日々点呼記録簿に記録し、1年間保存しなければならないとあります（出典: 国土交通省）。

運送事業を1人で行っている場合も、点呼は自ら実施する必要があるとされています（出典: 同ページ）。「1人だから記録簿は要らない」ということはありません。

### このテンプレートが国交省の例と違うところ

このページのテンプレートは、国交省の例と同じ並びの17列です。用紙の下の2つの注記も同じ文言です。そのうえで、1人親方が書きやすいように2か所を変えています。

- 上段の「会社名・営業所名」を「氏名・屋号」に
- 1列目の「運転者名・車両番号」を「車両番号」に（氏名は上段に1回書けば済むため）

列名は、欄が狭いので一部を短くしています。例えば「交替運転者に対する通告」は「交替運転者通告」です。中身は同じです。

記録は紙でなくても構いません。点呼の記録は、書面と電磁的方法の「いずれでも差し支えありません」とされています（出典: 国土交通省 FAQ）。紙が合わなければ、Excel やアプリでもよいということです。

## 2. 17列の全体像｜業務前8・業務後8・車両番号1

点呼記録簿の17列は、3つのまとまりに分かれます。左端の車両番号、業務前点呼の8列、業務後点呼の8列です。

![点呼記録簿は17列。車両番号1列と業務前8列・業務後8列に分かれ、前後で違うのは2列ずつ](/blog/tenko-kirokubo-template/columns.png)

業務前と業務後で、8列のうち6列は同じです。違うのは2列ずつだけ。そう覚えると、用紙がぐっと読みやすくなります。

| 列 | 業務前／後 | 書くもの |
|----|-----------|----------|
| 車両番号 | 共通 | ナンバー（例: 品川480 り 12-34） |
| 実施日時 | 両方 | 点呼をした月日と時刻 |
| 点呼方法 | 両方 | 「対面」か「その他（具体的な方法）」に○ |
| 点呼執行者 | 両方 | 点呼をした人の氏名 |
| アルコール検知器の使用の有無 | 両方 | 有・無に○ |
| 酒気帯びの有無 | 両方 | 有・無に○ |
| 疾病・疲労・睡眠不足等の状況 | 業務前 | 体調の確認結果 |
| 日常点検の状況 | 業務前 | 点検した、または点検済みを確かめた結果 |
| 自動車・道路及び運行の状況 | 業務後 | 運行中に気づいた車や道路の異変 |
| 交替運転者に対する通告 | 業務後 | 交替した相手に伝えたこと |
| その他必要な指示事項 | 両方 | 注意点や指示（業務前は天候など） |

### 上段の3つの欄

上段には「令和　年　月　日（　）」「氏名」「屋号」の欄があります。日付の欄は1つだけで、週の範囲を書く欄はありません。その用紙を使い始めた日を書いておきましょう。

### 業務前だけの列、業務後だけの列

業務前にあるのは、体調と日常点検の列です。日常点検の列は、点呼のたびに書く欄です。業務前の点呼では、日常点検の「実施又はその確認」を確かめるよう定められています（出典: 輸送安全規則 第7条）。点検したなら「済」、点検済みであることを確かめたなら「確認」のように、どちらか分かる形で書きましょう。

業務後にあるのは、運行の状況と、交替運転者への通告の列です。記録する欄で数えると、業務前は4つ、業務後は3つになります（酒気帯び・体調・日常点検・指示事項／運行の状況・通告・酒気帯び）。業務後を「2項目」とする説明もありますが、それは確認する事項の数え方です。

酒気帯びの確認は、業務前にも業務後にも必要です（出典: 同条）。どちらの列も「有・無」に○を付ける形で、数値を書く欄はありません。理由はよくある質問の Q2 で説明します。

## 3. 記入例｜1週間分を埋めるとこうなる

結論: 平常日は「○」や「問題なし」と短く書き、異変があった日だけ具体的に書きます。

ここでは、1人親方が月曜から土曜まで（水曜は休み）を1枚に書いた例を見てみましょう。上段は「令和8年11月9日（月）」「氏名: 山田太郎」「屋号: 山田軽運送」です。

毎日同じになる列は、表から省いています。点呼方法は「対面」に○、点呼執行者は「山田太郎」、検知器の使用は「有」、酒気帯びは「無」です。車両番号も毎日同じナンバーを書きます。

### 業務前の記入例

| 実施日時 | 疾病・疲労・睡眠不足等 | 日常点検 | 指示事項 |
|----------|----------------------|----------|----------|
| 11月9日 7:30 | ○ | 済 | |
| 11月10日 7:25 | 睡眠5時間。眠気なし。昼に仮眠をとる | 済 | |
| 11月12日 7:30 | ○ | 済 | 午後から雨。荷降ろしは足元注意 |
| 11月13日 7:35 | ○ | 済（左ミラーの締め直しを確認） | |
| 11月14日 7:30 | 問題なし | 済 | |

### 業務後の記入例

| 実施日時 | 自動車・道路及び運行の状況 | 交替運転者通告 | 指示事項 |
|----------|--------------------------|----------------|----------|
| 11月9日 18:10 | ○ | 該当なし | |
| 11月10日 18:30 | ○ | 該当なし | |
| 11月12日 19:05 | 左ミラーがぐらつく。帰着後に締め直した | 該当なし | |
| 11月13日 18:20 | ○ | 該当なし | |
| 11月14日 17:50 | 国道の工事で30分遅れ | 該当なし | |

休みの11月11日（水）は、点呼をしないので行を作りません。7行型なら、このまま1枚に1週間分が収まります。

書く量は、ほとんどの日が「○」と「済」だけです。「こんなに短くていいの？」と感じるかもしれませんが、問題はありません。国交省の睡眠不足に関する Q&A では、疾病・疲労・睡眠不足等の状況に問題がないことを確かめた結果として、チェックマークや「○」を記入してよいとされています（出典: 国土交通省 A10）。

ただし、「7時間」のように睡眠時間の数字だけを書くのは避けましょう。同じ Q&A は、睡眠不足だったかどうかが読み取れないとしています。11月10日の行のように、状況まで一言添えるのがコツです。

体調や日常点検の欄は、空欄のままにせず短く埋めておきましょう。指示事項は、特になければ空欄で構いません。異変があった日の書き方と、運行するかどうかの判断は、[軽貨物「点呼記録」の書き方](/blog/tenko-kiroku-kakikata)の第4章で詳しく扱っています。

### 1人親方が迷う3つの欄

1つ目は点呼方法です。用紙の注1のとおり、1人で事業を行い、自ら点呼した場合は「対面」に○を付けます（出典: 国土交通省「点呼記録簿の例」）。

2つ目は点呼執行者です。規則は「点呼を行った者」の氏名を記録するよう求めています。自分で点呼したので、自分の氏名を書きます。

3つ目は交替運転者通告です。この欄は、運転者が交替したときに伝えた内容を報告する欄です（出典: 輸送安全規則 第7条第2項）。1人で乗るなら通告はありません。空欄だと書き忘れと見分けにくいので、「該当なし」と書いておくのがおすすめです。

## 4. 7行型・10行型・Excelの選び方と使い始め

3つのファイルは、列と注記がすべて同じです。違うのは行数と、書く道具だけ。迷ったら次の図で選びましょう。

![迷ったら10行型。1週間で1枚にまとめたいなら7行型、パソコンで管理するならExcel](/blog/tenko-kirokubo-template/choose.png)

- 7行型（PDF）: 1行が高く、手書きの文字が収まりやすい型です。週7日走っても1週間で1枚に収まります
- 10行型（PDF）: 1枚に10日分。行は低めですが、ほとんどの日は「○」と「済」なので足ります。用紙の枚数を減らしたい人向け
- Excel: 10行型と同じ17列で、印刷範囲も設定済みです。パソコンで入力して保存できます

Excel は、出発前に毎回パソコンを開くのが手間になりがちです。点呼のときは紙に書き、あとで清書する、という二度手間も起きやすくなります。ふだんの持ち物に合わせて選ぶのがおすすめです。

### 使い始めの4ステップ

1. A4横で印刷する（PDF はどちらも1枚に収まる）
2. 上段に、使い始めた日付・氏名・屋号を書く
3. 業務前に左半分、業務後に右半分を1行で埋める
4. 埋まった用紙は月ごとに綴じ、1年間保存する

保存期間の1年は、輸送安全規則 第7条第5項で定められています。用紙の注2にも書いてあります。

綴じる場所は、日常点検の記録と同じバインダーにすると管理が楽です。日常点検のシートは[軽貨物の日常点検記録簿テンプレ](/blog/nichijou-tenken-kirokubo-template)で配っています。

## 5. 紙・Excel・アプリの比較

結論: どの方法でも法令上の差はありません。毎日やめずに続けられる方法を選びましょう。

| 項目 | 紙（PDFを印刷） | Excel | アプリ |
|------|----------------|-------|--------|
| 向いている人 | 書いて残すと落ち着く人 | 机でパソコンを使う人 | スマホを常に持つ人 |
| 毎日の手間 | ペンで○と短い記入 | 出発前に開くのが手間 | ボタンで選ぶ |
| 保存と見せ方 | 綴じて1年保管 | ファイルで保管・印刷 | 端末やクラウドに保存、PDFで出力 |

紙は、印刷さえすれば今日から始められます。弱点は、書き忘れた日に気づきにくいことと、1年分の紙がかさばることです。

Excel は、入力した内容をそのまま保存でき、読み返しやすいのが長所です。一方で、点呼は出発の直前と帰着の直後に行うものなので、その場でパソコンを開けるかどうかが続くかの分かれ目になります。

アプリの場合、delilog の点呼はアルコールの「使用の有無」「酒気帯びの有無」を2つのボタンで記録します。体調や日常点検、指示事項の欄は初期が空白で、入力は任意です。呼気の数値を残したい人は、任意で併記できます（初期設定はオフ）。

アカウント登録をしなくても始められます（記録は端末の中だけに残ります）。登録すると、クラウドに同期して機種変更や複数の端末にも対応できます。

PDF を出すときは、記録の無い日に「稼働なし」と自動で表示されます。出力には、設定で氏名と屋号を入れておく必要があります。

## よくある質問

### Q1. 国交省の点呼記録簿に Excel 版はありますか？

国交省の「点呼記録簿の例」は Word ファイルです。同じ国交省の制度改正ページでは、業務の記録と事故の記録の様式例が Excel で配られています。点呼記録簿を Excel で使いたい方は、このページの Excel 版をどうぞ。

### Q2. アルコールの数値を書く欄が無くても大丈夫ですか？

大丈夫です。国交省の「アルコール検知器の使用について」では、点呼簿への記載は検知器使用の「有・無」、酒気帯びの「有・無」で差し支えないとされています。測定数値を記載する必要もありません（出典: 国土交通省 A6・A12）。このページの対象事業者には、貨物軽自動車運送事業者も含まれています。

### Q3. 運転しない日の行はどうしますか？

運転しない日は、点呼をする場面がありません。その日の行は作らず、次に走る日を書きます。休んだ理由を書く必要もありません。delilog では、記録の無い日は PDF に「稼働なし」と自動で表示されます。休業理由を入力する機能はありません。

### Q4. 紙とアプリ、両方に残す必要はありますか？

点呼の記録は、書面か電磁的方法の「いずれでも差し支えありません」とされています（出典: 国土交通省 FAQ）。両方に残せという決まりは見当たりません。続けやすい方を1つ決めて、1年間保存しましょう。

## まとめ

点呼記録簿のポイントは3つです。

1. 様式は自由。国交省の例と同じ並びの17列があれば足りる
2. 迷ったら10行型。平常日は「○」「済」と短く書く
3. 1人親方は点呼方法を「対面」、執行者は自分の氏名。用紙は1年保存

まずは用紙を1枚印刷して、明日の業務前から書いてみましょう。欄ごとの書き方は[軽貨物「点呼記録」の書き方](/blog/tenko-kiroku-kakikata)、日常点検は[軽貨物の日常点検記録簿テンプレ](/blog/nichijou-tenken-kirokubo-template)が参考になります。
