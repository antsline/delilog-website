## 1. 形態別の早見表: 金額が公式ページに出ているのはどこ？

軽貨物の仕事は、大きく3つに分かれます。

- プラットフォーム型: アプリで案件を受ける（出前館・Amazon Flex など）
- 継続委託: 宅配会社などと継続的に契約する
- チャーター: 荷主の依頼ごとに運ぶ（赤帽など）

各類型の定義は働き方の記事に任せ、ここでは「公式ページに金額があるか」だけを見ます。2026年11月に、各社の公式ページを確認しました。

| 形態 | 事業者 | 公式ページの金額 |
| --- | --- | --- |
| アプリ型 | 出前館 | 基本報酬400円＋ブースト |
| アプリ型 | Amazon Flex | 4時間程度で最大9,600円（例示） |
| チャーター | 赤帽 | 20kmまで5,000円（税抜・運賃） |
| アプリ型 | Uber Eats | 確認できなかった |
| アプリ型 | PickGo | 確認できなかった |
| アプリ型 | Hacobell | 確認できなかった（割増料金のみ荷主向けに掲載） |
| 継続委託 | ヤマト | 確認できなかった（「高単価」の表現のみ） |
| 継続委託 | 佐川急便 | 確認できなかった |
| 継続委託 | Amazon Hub Delivery | 確認できなかった |
| 継続委託 | 日本郵便 | 個人事業主向けの募集要項を確認できなかった |

注記: 2026年11月に公式ページで確認しました。各ページに更新日の表記はありません。「確認できなかった」は、そのページに金額の記載が見当たらなかったという意味です。

![公式ページで金額を確認できたのは、出前館の基本報酬400円＋ブースト、Amazon Flexの最大9,600円（例示）、赤帽の20kmまで5,000円（運賃・税抜）の3例（2026年11月確認）](/blog/keikamotsu-tanka-soba-2026/koushiki-kingaku.png)

金額が出ていない理由を、公式ページから断定することはできません。登録後の画面で案件ごとに示される形や、説明会・面談で伝えられる形もあると考えられます。

今回確認したのは、表に書いたページの範囲です。問い合わせや説明会で、金額が示される可能性はあります。

結論として、金額が出ている3例は、そのまま収入の目安にはなりません。次の章から、それぞれ何を意味する数字なのかを見ていきます。

## 2. プラットフォーム型: 出前館の400円とFlexの例示、金額を確認できなかった3社

プラットフォーム型で知りたいのは、「公式の数字は自分の1時間あたりの収入になるのか」でしょう。順に見ます。

### 出前館: 400円は基本の部分

出前館の公式ページには、「基本報酬（400円）+ ブースト」とあります。400円は1配達の基本部分です。

ブーストは、配達距離、曜日や時間帯、天候などを考慮して上乗せされる報酬と説明されています。上乗せの金額は、公式ページに記載がありません。

支払いは、毎月15日と末日が締め日で、各締め日から5営業日以内に入金されるとされています（出典: 出前館の公式ページ）。

125ccを超えるバイクや車は、事業用ナンバーの車両のみ配達に使えます。黒ナンバーを取る必要があるという意味です。

### Amazon Flex: 最大9,600円は条件付きの例示

Amazon Flex の公式ページには、「4時間程度の稼働で最大9,600円」とあります。ただし、これは平均でも保証でもありません。

注釈によると、2025年4〜6月に関東圏で、軽貨物車が4時間程度稼働した場合を想定した例です。報酬はブロック単位で設定され、時期、配達エリア、デリバリーステーションによって変わります。

配達を始める前に、予定と報酬を確認できるとされています。

この例示を時給に換算するのはやめましょう。公式が、ブロックの稼働目安時間は実際の稼働時間と必ずしも一致しないと注記しているからです。

### PickGo・Hacobell・Uber Eats: 金額を確認できなかった

この3社は、公式ページで単価や時給、手数料率の金額を確認できませんでした。わかる範囲は、報酬の仕組みまでです。

- PickGo: 報酬はアプリ内のポイントに反映され、反映後はいつでも入金できると案内
- Hacobell: 荷主向けの割増料金は掲載。ドライバー報酬の記載は見当たらない
- Uber Eats: 配送料は、予定時間、受け取りと届け先の数、交通状況、注文量などを総合して算出と説明

求人サイトの「時給2,000円」などは、掲載元が示した金額です。公式ページの金額ではないため、この記事では使いません。

登録後に出るオファー画面で、金額、距離、拘束時間を確認してください。「金額 ÷ 自分の所要時間」で、受ける案件かどうかを判断するのがおすすめです。

## 3. 継続委託: 4社の公式ページで単価を確認できなかった。「想定月収」の読み方

継続委託の募集で気になるのは、「求人の月収例をどう受け取るか」でしょう。

ヤマト（フランチャイズ募集）、佐川急便、Amazon Hub Delivery の公式ページでは、単価や月収の金額を確認できませんでした。日本郵便は、個人事業主向けの募集要項を確認できませんでした。

ヤマトのページには「高単価を実現」という表現があります。しかし金額はなく、詳細は問い合わせや説明会で確認する案内です。「公表していない」と断言はできません。説明会や面談では、金額が示される可能性があります。

### 「想定月収」は上限の例示と考える

求人広告の「想定月収」は、多くの場合、条件が合った人の上限例です。平均ではありません。

公的統計で軽貨物個人事業主の単価を示すものは、確認できた範囲ではありませんでした。国交省の調査にある月収分布は、第5章で扱います。

求人票の自己申告の金額は、この記事の根拠にしません。数字を比べるより、契約前に条件を聞くほうが確実です。

### 面談で聞くこと

- 1個または1日あたりの単価はいくらか
- 働く日数と時間は、どのくらいを想定しているか
- 車両、燃料、保険は誰が負担するか
- 報酬の支払日はいつか
- 単価を改定するときのルールはどうなっているか

回答は、書面かメールで残しておきましょう。口頭だけだと、あとで「言った・言わない」になりやすいからです。

継続委託は、単価が決まれば毎月の見通しを立てやすい働き方です。だからこそ、契約前に単価と負担の範囲を確かめておくことが、収入を左右します。

## 4. チャーター: 赤帽の運賃表の読み方

結論: 赤帽の「20kmまで5,000円」は荷主が払う運賃です。そのまま自分の収入の目安にはなりません。

赤帽は、全国の組合をまとめる連合会の沿革に「荷物の共同受注」とあります（出典: [赤帽全国軽自動車運送協同組合連合会](https://www.akabou.or.jp/profile/)）。組合員が配送を担う仕組みです。運賃表は、荷主が払う料金の表と読んでください。

組合費や手数料がどう扱われるかは、組合ごとに違います。運賃との関係は公式ページで確認できませんでした。取り分は、所属する組合に確認するのが確実です。

### 距離制と時間制

取得元は、赤帽首都圏軽自動車運送協同組合の[料金案内](https://shutoken.akabou.jp/fare/)です（最大積載量350kgの車両・2026年11月に確認）。ページに改定日の表記はありません。

距離制は、20kmまでが5,000円です。21kmからは1kmごとに加算され、距離が延びるほど1kmあたりの額は下がります。休日（日曜・祝日）は2割増、深夜・早朝（22時〜5時）は3割増です。

![赤帽首都圏の運賃（税抜）は20kmまで5,000円で、距離が延びるほど1kmあたりの単価が220円から120円へ下がる（荷主が払う運賃で手取りではない）](/blog/keikamotsu-tanka-soba-2026/akabou-unchin.png)

全項目は次の表のとおりです。税込の額は、税抜に10%を足した額です。

| 区分 | 条件 | 運賃（税抜） |
|------|------|------|
| 距離制 | 20kmまで | 5,000円 |
| 距離制 | 21〜50km | 1kmにつき220円 |
| 距離制 | 51〜100km | 1kmにつき170円 |
| 距離制 | 101〜150km | 1kmにつき140円 |
| 距離制 | 151km以上 | 1kmにつき120円 |
| 時間制 | 2時間貸切・20kmまで | 5,500円 |
| 時間制 | 超過30分ごと | 1,250円 |
| 割増 | 休日 / 22〜5時 | 2割増 / 3割増 |
| 地区割増 | 東京特別区・大阪市 | 400円 |

### ほかの地域と標準的運賃

大阪府・愛知県・福岡県の各組合の公式ページでも、距離制・時間制・割増の数字は同じでした（2026年11月に確認）。ただし、全国で統一されているとは言えません。連合会は、改定の実施状況が地域ごとに異なると案内しています（出典: [赤帽連合会のお知らせ](https://www.akabou.jp/topics/detail/?no=861)）。ほかの地域は、各組合のページで確認しましょう。

「標準的運賃」を思い浮かべた方もいるでしょう。国交省の告示の件名は「一般貨物自動車運送事業に係る標準的な運賃」（令和6年国土交通省告示第209号）です。国交省と全日本トラック協会のページに、軽貨物の記載は確認できませんでした。

赤帽以外のチャーターについて、軽貨物単独の運賃表を公式ページで確認できた例はありませんでした。見積もりは、荷主ごとに個別に決まると考えておきましょう。

## 5. 月収と手取り: 売上は手取りではない

結論: 月収の数字を見たら、まず「経費と税・保険を引く前か後か」を確かめます。手取りは、自分の数字で順番に引いて出します。

### 月収の調査をどう読むか

国交省の適正化協議会の調査（令和5年3月・首都圏と近畿圏の個人事業主・有効回答772者）があります。月収は、通常期に39万円以下が8〜9割でした。50万円以上は、通常期で4%、繁忙期で16%です（出典: [国土交通省 資料3](https://www.mlit.go.jp/jidosha/content/001715726.pdf)）。分布の詳細は[年収・労働時間データの記事](/blog/keikamotsu-jittai-toukei)にまとめています。

注意点があります。調査項目は「平均月収」で、経費を引く前かどうかは、資料に記載がありません。求人の「月収50万円」も同じです。経費後の数字とは限りません。

### 手取りに至る順番

事業所得は、収入から必要経費を引いて求めます（出典: [国税庁 No.1350](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1350.htm)）。そこから税と保険料が引かれて、手元に残る額が決まります。

![売上から経費を引いて所得、さらに税・保険を引いたものが手取りになる流れ](/blog/keikamotsu-tanka-soba-2026/uriage-tedori.png)

この記事では、手取りの金額は試算しません。経費の比率に公的な出典がなく、国民健康保険は自治体で変わるためです。代わりに、引くものと確認先を表にしました。

| 引くもの | 決まり方 | 確認先 |
|------|------|------|
| 燃料・車両・保険などの経費 | 自分の帳簿 | 自分の記録 |
| 所得税 | 税率5〜45%の累進 | [国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 住民税 | 自治体ごと | お住まいの自治体 |
| 個人事業税 | 運送業は第一種事業。税率5%、事業主控除は年290万円 | [東京都主税局](https://www.tax.metro.tokyo.lg.jp/kazei/work/kojin_ji) |
| 国民年金 | 月額17,920円（令和8年度・定額） | [日本年金機構](https://www.nenkin.go.jp/service/kokunen/hokenryo/hokenryo.html) |
| 国民健康保険 | 自治体ごとに決まり方が違う | 自治体の試算ページ |

手順は3つです。直近3か月の売上を、取引先ごとに集めます。次に、燃料や車両の費用を同じ期間で集めます。最後に、表の確認先で税と保険料を調べて引きます。

ここで大事なのは、売上の記録です。取引先ごとの単価と日々の実績を残していれば、自分の売上が見えます。

## よくある質問

### Q1. 軽貨物で月収50万円は現実的ですか?

調査では、通常期に50万円以上は4%、繁忙期は16%でした。通常期は39万円以下が8〜9割です。

調査項目は「平均月収」で、経費を引く前かどうかは資料に記載がありません。求人の月収例は、上限の例示と考えましょう。

### Q2. Amazon Flex の時給はいくらですか?

公式ページに、時給の記載はありません。「4時間程度の稼働で最大9,600円」という例示があります。

これは2025年4〜6月に、関東圏で軽貨物車が稼働した場合の想定です。報酬はブロック単位で、時期・エリア・デリバリーステーションで変わります。時給には換算できません。求人サイトの金額は掲載元の提示額で、公式ページの金額ではありません。

### Q3. 赤帽の運賃表は、そのまま自分の取り分になりますか?

なりません。運賃表は荷主が払う料金です。組合員としての負担や取り分は、所属する組合に確認してください。

### Q4. 標準的運賃は軽貨物にも使えますか?

告示の件名は「一般貨物自動車運送事業に係る標準的な運賃」です。国交省と全日本トラック協会のページに、軽貨物の記載は確認できませんでした。軽貨物の見積もりの根拠として使える制度とは、現時点で言えません。
